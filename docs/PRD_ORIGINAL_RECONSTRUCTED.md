# 사진 기반 움직이는 이모티콘 제작 웹앱 PRD

> 문서 상태: **초기 복원본·참고용**  
> 현재 기준 요구사항은 [무료 우선 MVP PRD](PRD_FREE_FIRST_MVP.md)를 따른다.

> 문서 상태: 이전 대화에서 확정한 선택 사항을 기준으로 복원한 PRD
> 작성 시점: 2026년 8월

## 1. 제품 개요

사용자가 사진 한 장을 업로드하면 사진 속 인물이나 대상을 이모티콘 스타일 이미지로 변환하고, 문구와 움직임을 적용해 움직이는 이모티콘 파일로 저장할 수 있는 웹앱을 만든다.

핵심 기능은 **사진을 이모티콘 스타일로 변환하는 것**이다. 사용자는 복잡한 이미지 편집이나 애니메이션 제작 지식 없이 스타일, 문구, 움직임을 차례대로 선택하고 결과물을 만들 수 있어야 한다.

## 2. 문제 정의

일반 사용자가 자신의 사진으로 움직이는 이모티콘을 만들려면 다음과 같은 어려움이 있다.

- 사진 편집과 배경 정리가 어렵다.
- 이모티콘에 어울리는 짧은 문구를 생각하기 어렵다.
- 움직임을 직접 제작하려면 애니메이션 편집 도구가 필요하다.
- 속도와 반복 동작을 자연스럽게 조정하기 어렵다.
- 결과가 마음에 들지 않을 때 처음부터 다시 만들어야 한다.
- 완성된 결과물을 실제 파일로 저장하기 어렵다.

이 웹앱은 사진 업로드부터 스타일 변환, 문구 추천, 움직임 적용, 미리보기, 수정, 재생성과 파일 저장까지 한 흐름으로 제공한다.

## 3. 목표

### 핵심 목표

- 사진을 이모티콘 스타일 이미지로 변환한다.
- 직접 입력하거나 AI가 추천한 문구를 적용한다.
- 사용자가 원하는 움직임을 선택한다.
- AI가 움직임 속도를 자동으로 정하되 사용자가 수정할 수 있게 한다.
- 결과물을 즉시 미리 보고 원하는 부분만 수정하거나 다시 생성한다.
- 완성된 결과물을 파일로 저장한다.

### 사용자 가치

- 이미지 편집 경험이 없어도 개인 이모티콘을 만들 수 있다.
- 사진 선택부터 파일 저장까지 한 페이지 흐름으로 완료할 수 있다.
- AI 추천을 사용하되 최종 결과는 사용자가 직접 결정할 수 있다.

## 4. 대상 사용자

- 자신의 사진으로 개인 이모티콘을 만들고 싶은 사용자
- 가족, 친구, 반려동물 사진을 움직이는 이미지로 만들고 싶은 사용자
- 메신저나 SNS에서 사용할 짧은 반응형 이미지를 만들고 싶은 사용자
- 전문 이미지·모션 편집 도구 사용 경험이 없는 일반 사용자

## 5. 핵심 사용자 흐름

```text
사진 선택
→ 사진 미리보기
→ 이모티콘 스타일 선택
→ 문구 직접 입력 또는 AI 추천
→ 움직임 선택
→ AI가 움직임 속도 자동 설정
→ 사용자가 속도 수정 가능
→ 이모티콘 생성
→ 결과 미리보기
→ 원하는 항목 수정 또는 재생성
→ 완성 파일 저장
```

사용자가 이미지를 선택한 뒤에는 반드시 다음 순서로 제작한다.

1. 스타일 선택
2. 문구 선택 또는 입력
3. 움직임 선택
4. 생성

## 6. 기능 요구사항

### 6.1 사진 업로드

- 사용자는 기기에서 사진을 선택할 수 있다.
- 선택한 사진은 생성 전에 미리 보여준다.
- 잘못 선택한 사진은 제거하거나 다른 사진으로 교체할 수 있다.
- 지원하지 않는 파일은 이유를 안내하고 업로드를 막는다.
- 파일 용량이 너무 큰 경우 사용자가 이해할 수 있는 오류를 표시한다.
- 생성 중에도 원본 사진은 유지되어야 한다.

지원 파일 형식, 최대 용량, 최대 해상도는 실제 구현 환경에 맞춰 확정하되 화면에 명확하게 안내한다.

### 6.2 이모티콘 스타일 변환

- 웹앱의 첫 번째 핵심 기능은 사진을 이모티콘 스타일로 변환하는 것이다.
- 사용자는 사진 업로드 후 변환 스타일을 선택한다.
- 스타일을 선택하기 전에 각 스타일의 차이를 미리 이해할 수 있어야 한다.
- 변환 결과는 원본 사진의 핵심 인물이나 대상 특징을 유지해야 한다.
- 결과가 마음에 들지 않으면 같은 사진으로 다시 생성할 수 있다.
- 다시 생성하더라도 원본 사진과 사용자가 입력한 설정은 유지한다.

구체적인 스타일 이름과 개수는 최종 디자인 단계에서 확정한다. 스타일은 카드형 선택 UI로 제공하는 것을 기본으로 한다.

### 6.3 문구 입력과 AI 추천

문구는 두 가지 방식으로 정할 수 있다.

1. 사용자가 직접 입력
2. AI가 추천한 문구 선택

필수 동작은 다음과 같다.

- 사용자는 원하는 문구를 직접 입력할 수 있다.
- AI는 사진 또는 사용자가 지정한 분위기를 참고해 짧은 문구를 추천한다.
- AI 추천 문구는 여러 개 보여준다.
- 추천 문구를 선택한 뒤 직접 수정할 수 있다.
- AI 추천을 사용하지 않고 직접 입력만으로 생성할 수 있다.
- 문구 없이 이모티콘 이미지만 만들 수 있는 선택지도 고려한다.
- 문구가 너무 길면 권장 길이를 안내한다.
- 문구가 이미지 밖으로 잘리지 않게 자동 배치한다.

AI 문구 추천은 최종 결정을 대신하지 않는다. 사용자가 선택하거나 수정한 문구만 결과물에 적용한다.

### 6.4 움직임 선택

기본 움직임은 다음과 같다.

- 통통 튀기
- 좌우 흔들기
- 끄덕이기
- 고개 갸웃하기
- 손 흔들기
- 춤추기
- 눈 깜빡이기
- 표정 바꾸기

기능 요구사항은 다음과 같다.

- 움직임은 이름과 간단한 예시를 함께 제공한다.
- 사용자는 생성 전에 움직임을 선택할 수 있다.
- 선택한 움직임은 미리보기에서 반복 재생한다.
- 움직임을 변경해도 스타일과 문구 설정은 유지한다.
- 사진 구조상 특정 움직임을 적용하기 어려운 경우 다른 움직임을 추천한다.
- 손, 얼굴 등 필요한 영역을 인식하지 못한 경우 사용자에게 안내한다.

### 6.5 움직임 속도

- 기본 속도는 AI가 사진과 움직임에 맞춰 자동으로 정한다.
- 사용자는 AI가 정한 속도를 직접 수정할 수 있다.
- 속도 조절은 느리게, 기본, 빠르게처럼 이해하기 쉬운 방식으로 제공한다.
- 필요하면 세부 슬라이더를 함께 제공할 수 있다.
- 속도를 바꾸면 결과를 다시 생성하기 전에 미리보기로 확인할 수 있어야 한다.
- 너무 빠르거나 부자연스러운 속도는 기본 추천값으로 보정한다.

### 6.6 생성

- 스타일, 문구, 움직임을 고른 뒤 생성 버튼을 누른다.
- 생성 중에는 진행 상태를 보여준다.
- 생성 버튼을 반복해서 눌러 중복 작업이 발생하지 않게 한다.
- 생성 중 실패하면 입력값을 유지하고 다시 시도할 수 있게 한다.
- 결과 생성에 시간이 걸릴 경우 현재 처리 단계를 안내한다.

### 6.7 결과 미리보기

- 완성된 이모티콘은 화면에서 바로 반복 재생한다.
- 재생과 일시정지를 제공한다.
- 적용된 스타일, 문구, 움직임, 속도를 함께 확인할 수 있다.
- 실제 저장될 결과의 비율과 잘림 상태를 확인할 수 있어야 한다.
- 배경이 투명한 경우 체크무늬 등으로 구분해 보여준다.

### 6.8 수정과 재생성

결과가 마음에 들지 않을 때 다음 두 가지 방식을 제공한다.

1. 원하는 설정만 수정해 다시 적용
2. 같은 설정으로 결과 전체 재생성

수정 가능한 항목은 다음과 같다.

- 스타일
- 문구
- 움직임
- 움직임 속도

재생성 시 원본 사진과 기존 설정을 유지한다. 사용자가 처음부터 다시 입력하게 만들지 않는다.

### 6.9 파일 저장

- 완성 결과물은 사용자의 기기에 파일로 저장할 수 있어야 한다.
- 저장 버튼은 결과 미리보기 화면에서 명확하게 제공한다.
- 저장 준비 중, 저장 완료, 저장 실패 상태를 표시한다.
- 생성 결과가 완성되기 전에는 저장 버튼을 비활성화한다.
- 저장에 실패하면 다시 시도할 수 있게 한다.
- 저장 파일명은 사용자가 구분할 수 있는 기본 이름을 자동 생성한다.

최종 저장 형식과 해상도는 구현 환경에서 확정한다. 단, 움직임이 유지되는 형식을 반드시 하나 이상 지원해야 한다.

## 8. AI 역할

AI는 다음 영역을 보조한다.

- 사진을 이모티콘 스타일로 변환
- 사진이나 분위기에 어울리는 짧은 문구 추천
- 선택한 움직임에 자연스러운 기본 속도 추천
- 적용하기 어려운 움직임 대신 사용 가능한 움직임 추천

AI 결과는 항상 사용자가 확인하고 수정할 수 있어야 한다.

AI가 만든 결과를 사용자 확인 없이 자동으로 최종 저장하지 않는다.

오류가 발생해도 가능한 경우 사용자가 입력한 사진과 설정을 유지한다.

## 10. 비기능 요구사항

### 사용성

- 처음 방문한 사용자도 설명 없이 흐름을 이해할 수 있어야 한다.
- 한 화면에서 너무 많은 설정을 동시에 요구하지 않는다.
- 현재 제작 단계를 표시한다.
- 이전 단계로 돌아가도 입력값을 유지한다.

### 반응형

- 모바일과 PC 웹에서 모두 사용할 수 있어야 한다.
- 모바일에서는 버튼과 선택 카드의 터치 영역을 충분히 확보한다.
- 미리보기 결과가 화면 밖으로 잘리지 않아야 한다.

### 성능

- 고용량 사진 처리 중에도 화면이 멈춘 것처럼 보이지 않게 한다.
- 생성 중 진행 상태를 보여준다.
- 같은 요청이 중복 실행되지 않게 한다.

### 개인정보

- 사용자가 올린 사진의 처리 및 보관 방식을 명확하게 안내한다.
- 불필요하게 원본 사진을 장기 보관하지 않는다.
- 사진 삭제 요청 또는 작업 종료 시 처리 정책을 제공한다.

- 여러 사진을 사용한 이모티콘 세트
- 메신저별 내보내기 규격

P1과 P2 항목은 당시 핵심 흐름을 해치지 않는 범위에서 이후 검토한다.

## 12. 완료 조건

다음 조건을 충족하면 MVP가 완료된 것으로 본다.

1. 사용자가 사진을 선택하고 미리 볼 수 있다.
2. 사진을 이모티콘 스타일로 변환할 수 있다.
3. 문구를 직접 입력하거나 AI 추천에서 선택할 수 있다.
4. 추천 문구를 직접 수정할 수 있다.
5. 기본 움직임 중 하나를 선택할 수 있다.
6. AI가 기본 움직임 속도를 설정한다.
7. 사용자가 속도를 수정할 수 있다.
8. 완성 결과를 반복 재생해 확인할 수 있다.
9. 원하는 설정만 수정할 수 있다.
10. 같은 설정으로 전체 결과를 다시 생성할 수 있다.
11. 결과물을 움직임이 유지되는 파일로 저장할 수 있다.
12. 생성이나 저장이 실패해도 원본 사진과 설정이 유지된다.

## 13. 최종 확정 사항

- 가장 먼저 완성할 핵심 기능은 사진을 이모티콘 스타일로 변환하는 기능이다.
- 제작 순서는 스타일, 문구, 움직임을 선택한 뒤 생성하는 방식이다.
- 문구는 직접 입력과 AI 추천을 모두 제공한다.
- 기본 움직임은 통통 튀기, 좌우 흔들기, 끄덕이기, 고개 갸웃하기, 손 흔들기, 춤추기, 눈 깜빡이기, 표정 바꾸기다.
- 움직임 속도는 AI가 자동으로 정하고 사용자가 수정할 수 있다.
- 결과가 마음에 들지 않으면 원하는 항목만 수정하거나 전체를 재생성할 수 있다.
- 완성된 결과물은 반드시 파일로 저장할 수 있어야 한다.
